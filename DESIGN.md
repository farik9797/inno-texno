# DESIGN — INNO TEXNO

## Сцена
Диспетчерская дорожной службы ночью: тёмный асфальт, на нём горят LED-сигналы. Тёмная тема — не «потому что технологично», а потому что продукт — источники света, и на тёмном они читаются как в жизни.

## Цветовая стратегия
Committed dark: тёмная поверхность несёт бренд, два акцента — сигнальный жёлтый (CTA, внимание) и LED-зелёный (успех, «разрешено»). Красный — только внутри визуала светофора, не UI-цвет. Цвета зафиксированы клиентом в брифе (чёрный, тёмно-серый, зелёный, жёлтый).

### Токены (OKLCH)
- `--bg`        oklch(0.16 0.01 250)  — асфальт, почти чёрный с холодным подтоном
- `--surface`   oklch(0.21 0.012 250) — панели/карточки
- `--surface-2` oklch(0.25 0.014 250) — приподнятые элементы
- `--ink`       oklch(0.95 0.005 250) — основной текст
- `--ink-muted` oklch(0.72 0.01 250)  — вторичный текст (контраст ≥4.5:1 на bg)
- `--amber`     oklch(0.84 0.17 90)   — сигнальный жёлтый, CTA
- `--green`     oklch(0.78 0.19 150)  — LED-зелёный, успех/акцент
- `--line`      oklch(0.32 0.012 250) — бордеры

## Типографика (Cyrillic + Latin обязательны — UZ/RU/EN)
- Display: **Unbounded** 500/600 — широкий техно-гротеск, характер LED-табло
- Body: **IBM Plex Sans** 400/500/600 — инженерный, читаемый, полная кириллица
- Tech: **JetBrains Mono** 400/500 — характеристики, цифры, лейблы
- Display letter-spacing ≥ −0.02em; clamp max ≤ 4.5rem; body line-length ≤ 72ch

## Motion
GSAP + ScrollTrigger (статичный HTML — правило из CLAUDE.md). Reveal только усиливает видимый по умолчанию контент. ease-out-quart. `prefers-reduced-motion` — всё статично, светофор замирает на зелёном.

## 3D
Zdog-светофор в hero: псевдо-3D, drag-rotate, цикл сигналов красный→жёлтый→зелёный, glow через CSS drop-shadow на canvas. Vanilla-tilt (max 7°) на карточках каталога. Тяжёлый WebGL не используем — бриф требует загрузку 2–3 с.

## Иконки
UI — Lucide через Iconify (`<iconify-icon>`), соцсети — Simple Icons CDN. Ручных SVG-путей нет (правило icons.md). Продуктовые визуалы светофоров — originate: собраны из CSS-примитивов.

## Запреты (сверх глобальных банов impeccable)
Никаких eyebrow-лейблов над каждой секцией; нумерация только у реального процесса заказа (он — настоящая последовательность из брифа). Радиус карточек ≤ 14px. Без стеклянных карточек и градиентного текста.
