## Ключевые решения (и почему)
- Тёмная тема: продукт — источники света; сигналы читаются как в жизни. Цвета зафиксированы клиентом в брифе
- Ванильный CSS вместо Tailwind CDN: бриф требует загрузку 2–3 с; кастомная дизайн-система в один файл легче
- Zdog вместо Three.js для 3D: ~28 КБ против сотен, достаточно для декоративного hero (скилл lightweight-3d-effects)
- GSAP возвращён по запросу клиента, но только для scrub-эффектов (двигают видимый контент, не прячут его) — entrance-reveals остались на CSS+IO, поэтому «ships blank» невозможен
- `!important` на #tl-canvas в @media 680: Zdog ставит инлайн width при retina-скейлинге
- Отзывы — обобщённые должности без названий организаций (не выдумывать конкретных клиентов)
