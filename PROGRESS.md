## Структура файлов
- `index.html` — главная; `katalog.html` — каталог и цены
- `assets/css/style.css` — вся CSS (общая для страниц)
- `assets/js/i18n.js` — все строки UZ/RU/EN (ключи главной + блок каталога через `Object.assign`)
- `assets/js/site.js` — общее поведение: языки (`applyLang` → событие `langchange`), прелоадер, шапка/меню/scrollspy, reveal, кнопки `[data-product]` → автозаполнение формы, отправка формы
- `assets/js/catalog-data.js` — `CATALOG`: светофоры, 6 групп опор (53 варианта), 8 единиц оборудования, ИИ-система
- `assets/js/katalog.js` — рендер каталога из `CATALOG`, пересборка при смене языка
- Инлайн-скрипт в `index.html` — только своё: Zdog-светофор, tilt, GSAP, калькулятор, видео
- `assets/docs/` — патент UZ SAP 2888 и выписка из реестра (PDF от клиента)
- `assets/js/products.js` — `PRODUCTS`: 17 страниц товаров (slug, категория, refs → позиции `CATALOG`, описание, характеристики, похожие)
- `assets/js/product.js` — рендер страницы товара; те же функции использует сборщик
- `tools/build-products.mjs` — генерирует `mahsulot/*.html` (статический UZ-контент для SEO, Schema.org Product/Offer + BreadcrumbList, canonical, og) и `sitemap.xml`. Шапку/футер/форму берёт из `katalog.html`
- **После любой правки `catalog-data.js`, `products.js`, `i18n.js` или шапки в `katalog.html` — запустить `node tools/build-products.mjs`** (сгенерированные страницы руками не править)

## Ключевые решения (и почему)
- Тёмная тема: продукт — источники света; цвета зафиксированы клиентом в брифе
- Ванильный CSS/JS без сборки: бриф требует загрузку 2–3 с, хостинг — GitHub Pages
- Каталог рендерится из `catalog-data.js`, данные сгенерированы из xlsx скриптом — исключает ошибки переписывания 65 цен; при новом прайсе — перегенерировать тем же способом
- Опоры — таблицами по группам, а не 53 карточками: B2B-покупатель сравнивает высоты/консоли в одной группе
- Страница товара = модель, не вариант: 53 страницы-дубля опор (разница только в высоте) плохи для SEO и сравнения; варианты — в селекте на одной странице
- Страницы товаров статические (генерируются), а не `?id=` + JS: поисковики индексируют готовый текст; язык переключается тем же рендером в браузере
- Схемы опор нарисованы CSS-примитивами (нет своих фото, чужие брать не стали)
- Zdog вместо Three.js; GSAP только scrub; `!important` на #tl-canvas в @media 680 (Zdog ставит инлайн width)
- На странице каталога нет прелоадера и GSAP — внутренняя страница должна открываться мгновенно
